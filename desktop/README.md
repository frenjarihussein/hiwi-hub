# نسخة سطح المكتب (Windows) — Yousef Soft

## كيف تعمل
عند فتح البرنامج يشغّل في الخلفية "خادماً محلياً" (`yousef-server`) يحتوي:
1. PostgreSQL محمول — البيانات في `%APPDATA%/com.yousefsoft.desktop`.
2. PostgREST (واجهة الجداول) + GoTrue (تسجيل الدخول) — لأن البرنامج يعتمد على تسجيل الدخول وسياسات الأمان.
3. خادم التطبيق داخلياً على `127.0.0.1:3000`، ونافذة البرنامج تتصل بالبوابة على `127.0.0.1:3001`.

عند أول تشغيل يُطبَّق ملف المخطط `hiwi-hub-schema-v2.sql` على القاعدة الفارغة.
عند إغلاق النافذة يتوقف كل شيء.

## خطوات البناء (على جهاز Windows)
1. ثبّت: Rust (rustup)، Bun، و `cargo install tauri-cli --version ^2`.
2. جهّز مجلد `desktop/src-tauri/binaries/stack/` يحتوي:
   - `pgsql/` (PostgreSQL 15 المحمول لويندوز: zip من EnterpriseDB)
   - `postgrest.exe` و `gotrue.exe` (من صفحات إصدارات GitHub)
   - `hiwi-hub-schema-v2.sql`
   - `app-cmd.json` يحدد أمر تشغيل خادم الواجهات، مثال: `{"cmd":"node","args":["app/server.js"]}`
3. ابنِ الواجهات بعنوان محلي: `VITE_SUPABASE_URL=http://127.0.0.1:54321 bun run build`
4. ابنِ المشغّل:
   `bun build --compile --target=bun-windows-x64 desktop/server/yousef-server.ts --outfile desktop/src-tauri/binaries/yousef-server-x86_64-pc-windows-msvc.exe`
5. مفاتيح الاتصال تُنشأ لكل تثبيت وتُحقن تلقائياً؛ لا تنسخ الأسرار بين العملاء أو تضعها داخل الواجهات.
6. من `desktop/src-tauri`: `cargo tauri build` ← ملف التثبيت.

## المنافذ المحلية
3001 نافذة البرنامج واتصال الشبكة الداخلية · 54321 بوابة داخلية · 54322 Postgres · 3000 خادم داخلي.

## حدود هذه النسخة
- ربط Sungrow/SMA وتلغرام والذكاء الاصطناعي يحتاج إنترنت.
- البيانات على جهاز ويندوز الرئيسي؛ أجهزة أندرويد على الشبكة تقرأ وتكتب على الجهاز نفسه.
- بناء ويندوز يستخدم خادم Node مستقل، ولا يغيّر نشر النسخة السحابية.
- لم تُبنَ الحزمة أو تُختبر على ويندوز حتى الآن.

## البناء التلقائي على GitHub (بدون جهاز ويندوز)
1. في GitHub افتح المستودع ← تبويب **Actions** ← **Build desktop installer** ← **Run workflow**.
2. انتظر انتهاء البناء (20–40 دقيقة أول مرة).
3. افتح نتيجة التشغيل وحمّل **YousefSoft-Setup** (يحتوي ملف التثبيت `.exe`).

## التفعيل وأول استخدام
1. شغّل المثبت ثم افتح البرنامج على الكمبيوتر الرئيسي.
2. أرسل رمز الجهاز الذي يظهر إلى مدير البرنامج.
3. من النسخة السحابية: إدارة النظام ← تراخيص الديسكتوب ← أدخل الرمز واسم الزبون والمدة ← توليد المفتاح.
4. انسخ المفتاح إلى شاشة الكمبيوتر واضغط تفعيل؛ التحقق محلي ولا يحتاج إنترنت.
5. أنشئ حساب مدير النسخة المحلية ثم الشركة والمستخدمين. الحسابات السحابية لا تُنسخ تلقائياً.
6. افصل الإنترنت وجرب تسجيل الدخول وفاتورة ومرفق، ثم أغلق البرنامج وافتحه وتحقق من بقاء البيانات.

## أندرويد والشبكة الداخلية
1. اترك برنامج ويندوز مفتوحاً، ووصل الهاتف والكمبيوتر بشبكة موثوقة واحدة.
2. اعرف عنوان IPv4 للكمبيوتر وأدخل مثلاً `192.168.1.10:3001` في تطبيق أندرويد.
3. اسمح في جدار ويندوز بالمنفذ TCP 3001 للشبكات الخاصة فقط. لا تفتح 54322 أو 54321 ولا تعمل تحويل منافذ على الراوتر.
4. فعّل النسخة وأنشئ المدير من الكمبيوتر أولاً، ثم استخدم حساباً محلياً على الهاتف.
5. شاشة اختيار الخادم تظهر عند فتح التطبيق مجدداً، مع زر متابعة آخر خادم؛ لا حاجة لمسح بيانات التطبيق.
6. LAN لا يحتاج إنترنت، لكنه يحتاج الكمبيوتر والشبكة. الخيار السحابي يحتاج إنترنت. لا توجد قاعدة مستقلة كاملة داخل الهاتف.
7. اتصال HTTP الداخلي غير مشفر: استخدم شبكة خاصة موثوقة؛ لا تستخدمه على Wi-Fi عام.

## إصدار APK قابل للتحديث
احفظ في GitHub ← Settings ← Secrets and variables ← Actions:
`ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_PASSWORD`, `ANDROID_KEY_ALIAS`.
يجب أن تكون قيمها من مفتاح توقيع أندرويد خاص ثابت تحتفظ بنسخة احتياطية منه؛ لا تضعها في المستودع أو الدردشة.
بدونها يتوقف إصدار APK بدلاً من إنتاج إصدار بتوقيع مؤقت. الإصدارات السابقة ذات المفاتيح المؤقتة قد تحتاج إعادة تثبيت.
شغّل **Build Android app** ثم نزّل **YousefSoft-Android**. إصدار هذه الحزمة مخصص لأجهزة ARM64.

## التحديث والنسخ الاحتياطي
خذ نسخة احتياطية من الشركة والمرفقات قبل أي تحديث، وأغلق البرنامج، ثم ثبت الإصدار الجديد بنفس معرّف التطبيق.
لا تحذف مجلد بيانات البرنامج. المخطط الأساسي يطبق مرة واحدة؛ ترحيلات مستقبلية تضاف إلى `stack/local-migrations` وتنفذ مرة واحدة بالترتيب.
التراخيص والبيانات والمرفقات محفوظة خارج مجلد التثبيت. النقل إلى كمبيوتر جديد يحتاج ترخيصاً لبصمته الجديدة.

## نتيجة التحقق وحدود الأمان
تم اختبار استعادة ملف المخطط في PostgreSQL 17 مع كائنات التوافق المحلية، ورفع/توقيع/قراءة/حذف مرفق تحت RLS، وتمرير الاتصال الداخلي ومنع origin أجنبي، و13 اختباراً للتوقيع وربط الجهاز والعناوين.
المثبت وAPK لم يُختبرا على أجهزة حقيقية هنا؛ نجاح البناء ليس إثباتاً لاكتمال التشغيل أوفلاين.
سحب الترخيص يصل عند أول إبلاغ ناجح بالإنترنت؛ عند عدم الاتصال لا يمكن إيقاف الجهاز عن بعد.
الترخيص يصعّب النسخ ولا يجعل البرنامج مستحيلاً للاختراق، وصاحب صلاحيات الكمبيوتر يستطيع العبث بالملفات.
